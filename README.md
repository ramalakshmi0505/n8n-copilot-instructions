# 🤖 n8n Workflows — GitHub Copilot Instructions

**Author:** Ramalakshmi Mani (Rama) | Senior Cloud & Platform Engineer @ BMW TechWorks

This repo contains custom GitHub Copilot instructions tailored for **n8n workflow automation**
development — covering AI agents, integrations, security, and platform engineering standards.

---

## 📄 What is `copilot-instructions.md`?

GitHub Copilot reads `.github/copilot-instructions.md` automatically and uses it to give
**project-aware, context-specific code suggestions** instead of generic ones.

Think of it as a **skills.md for your AI coding assistant** — you define the rules,
Copilot follows them across every file in your repo.

---

## ✅ What This Covers

| Area | Rules Defined |
|------|--------------|
| 🔐 Security | No hardcoded secrets, HTTPS only, least privilege |
| 🤖 AI Agents | System prompts, max iterations, fallback logic |
| 🧩 n8n Standards | Node naming, error handling, sticky notes |
| 🐍 Python | Type hints, error handling, requests with timeout |
| 🌐 JavaScript | const/let, optional chaining, n8n return format |
| 📁 Folder Structure | Consistent repo organization |
| 📝 Git Commits | Conventional commits format |

---

## 🚀 How to Use

1. Copy `.github/copilot-instructions.md` into your n8n repo
2. Customize rules to match your team standards
3. GitHub Copilot picks it up automatically — no setup needed!
